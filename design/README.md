# Sift — AI 原生 Mac 磁盘空间管理器

Svelte 5（runes）+ Vite 6 + Tailwind CSS 4 + TypeScript 高保真原型。

## 核心理念

参考 DaisyDisk 的地图化空间浏览，但 AI 是图上的一层"判定视图"：
方块面积对应占用（自适应权重压缩 + 长尾「其他」兜底），AI 结论以
角标/颜色呈现，点击候选可直接加入清理。

## 界面

- 顶部：磁盘选择（多卷宗，可用空间融入选择器）+ 常驻面包屑
- 画布主体：左侧 Treemap 方块面积图，右侧沉浸式目录列表（无分割线、
  内阴影表达层级）
- 底部 AI 摘要胶囊：点击后**胶囊边框直接长大**为锚定在其上方的弹出
  菜单（清理候选 / 例行任务两个 Tab），关闭时缩回胶囊；背景压暗模糊
- 标题栏：自动整理纯 switch；关闭时按钮为「磁盘扫描」，开启时为
  「智能扫描」

## 运行

```bash
pnpm install
pnpm dev
```

> 本机 npm 在该带空格路径下会异常短路，请使用 pnpm。
> 扫描与删除为前端模拟，所有数值为演示数据。

## 验证

- `vite build`：成功（JS ≈111 kB / gzip ≈40.7 kB，CSS ≈30 kB）
