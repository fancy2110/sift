# Sift 软件说明

Sift 是一款面向 macOS 的磁盘空间管理器：扫描磁盘、找出可清理的内容、安全地清理，并把结论沉淀成可复用的定时任务。它不追求「一键清空」，而是让每一次删除都有依据、可回看、可撤销。

## 适合谁

- 磁盘经常告急、又不敢乱删的开发者和创作者；
- 希望把「清理缓存 / 构建产物 / 旧安装包」变成固定流程的人；
- 想用 AI 辅助判断，但不愿把删除决定交给模型的人。

## 核心能力

**扫描与定位**：整盘或指定目录扫描，实时进度、可取消；树形浏览与体积占比，快速找到大目录。

**智能清理**：本地规则先筛选候选，AI 给出可删性、安全等级与原因（只确认或削弱，不会单独把未知项标成安全）。确认后统一移入回收站，逐项显示结果，随时可取消，全部记入历史。

**定时任务**：一个列表管理所有周期性清理，支持执行、编辑、删除。三种创建方式——手动填写、规则匹配（目录 + 文件名正则 + 天数）、一句话让 AI 生成草稿。例行任务按每天 / 每周 / 每月执行，默认执行前确认。

**后台值守**：菜单栏常驻，监控剩余空间，低于阈值时提醒；可开启每日定时清理。

## 安全与隐私

- 只移入系统回收站，应用内没有永久删除；
- 删除前校验文件指纹，路径变化即放弃；
- 规则与定时任务始终为「执行前确认」；
- AI 需显式开启并同意，只发送必要文本与脱敏元数据，不上传文件内容；
- API Key 保存在本机 `~/Library/Application Support/Sift/`（权限 0600），不写入设置、不入库。

## AI 配置

支持多套配置并存，各自保存 Key，随时切换：

| 服务商 | 接口 |
| --- | --- |
| 火山方舟 | `/api/v3`（平台 Key）或 `/api/plan/v3`（Agent Plan Key） |
| DeepSeek | `https://api.deepseek.com/chat/completions` |
| OpenAI | `https://api.openai.com/v1/chat/completions` |
| Anthropic Claude | `https://api.anthropic.com/v1/messages` |

在「设置 → 智能梳理」中新建配置，填入接口地址、模型与该服务商的 Key；选中哪套就用哪套。AI 调用会产生相应费用。

## 使用流程

1. 首次打开选择起始目录并扫描；
2. 在「智能」列表查看建议，勾选要清理的项（可只看已选）；
3. 确认清理 → 文件进入回收站；
4. 需要周期清理时，在「例行任务」中添加定时任务（手动 / 规则 / AI）；
5. 在设置中开启每日定时清理与低空间提醒。

## 系统要求

- macOS 13 或更高（Apple Silicon / Intel）；
- 首次扫描需授予「完全磁盘访问权限」；
- AI 功能需要网络与可用的 API Key。
