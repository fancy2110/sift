## 亮点

0.2.0 把 Explorer 做成了真正的 Finder 风格文件浏览器，并让 AI 判定直接出现在每一行里。

- 分栏浏览 + 双栏联动 + 面包屑路径，目录总量自动统计并缓存。
- 每个子项内联 AI 判定，选中目录可让 AI 解释它是什么、能不能删。
- 列表可按大小排序，分析进度直接可见。
- 计划任务支持「只分析 / 自动执行」，结果默认先待用户确认。
- AI 设置支持自定义分析提示词和更多服务商预设。

## 更新内容

### 新增
- Explorer 分栏浏览、双栏联动与面包屑路径栏。
- 每个子项的内联 AI 判定，以及选中目录的 AI 解释。
- 目录大小缓存与显式重扫；选中目录自动统计总量。
- 列表按大小排序与可见的分析进度。
- 自定义 AI 分析提示词、服务商下拉选择与更多预设。
- 计划任务可在「只分析」和「自动执行」之间切换，到点结果先待确认。

### 变更
- Explorer 保留磁盘选择与面包屑路径；左栏显示右栏目录的父目录。
- 设置页 AI 选项合并，自动清理移到分组底部。
- Explorer 标签页激活时自动刷新。
- Release 构建迁移到 macOS 15 runner（macOS 14 镜像已于 2026-11-02 退役）。

### 修复
- 菜单栏图标填满画布，更容易辨认。
- 根目录作为第一个面包屑，去掉重复的卷名。
- AI 进度显示在按钮上，回答跟随界面语言。
- 左栏或面包屑变化时，Explorer 行保持正确。
