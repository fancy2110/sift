## 亮点

Sift 首个公开版本：macOS 磁盘空间管理器，所有删除只进回收站，模型只能佐证结论、不能单独授权删除。

- 批量 `getattrlistbulk(2)` 枚举，61 万文件 / 57 GB 约 2.3 秒。
- 清理只进回收站，逐项结果并保留历史。
- 定时任务支持手动、正则规则、AI 草稿三种创建方式。
- 多套 AI 配置各自独立 Key，随时切换。

## 更新内容

### 新增
- 整盘 / 目录扫描，实时进度与取消。
- 树形浏览、体积占比与「只看已选」筛选。
- 仅回收站清理、逐项结果与历史。
- AI 判定：火山方舟（平台 + Agent Plan）、DeepSeek、OpenAI、Anthropic Claude。
- 定时任务：按周期的例行任务，以及目录 + 文件名正则规则。
- 手动 / 规则 / AI 三种创建方式，统一在一个对话框中。
- 菜单栏监控、低空间提醒与定时清理。
- 8 种界面语言与 Lucide 图标。

### 修复
- 删除后目录大小与卷容量同步更新。
- 取消重扫不再残留旧状态。
- macOS 移入回收站不再产生逐项提示音。
- 指纹校验改用逻辑大小。
