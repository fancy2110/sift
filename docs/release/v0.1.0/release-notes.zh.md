# Sift v0.1.0 发布说明

发布日期：2026-10-26 ｜ 平台：macOS（Apple Silicon / Intel）

Sift 的第一个可用版本：一个把「扫描、判断、清理、复盘」串成闭环的 macOS 磁盘空间管理器。删除永远只进回收站，AI 只能佐证、不能单独决定删除。

## 亮点

- **快**：`getattrlistbulk(2)` 批量枚举，61 万文件 / 57 GB 约 2.3 秒；整卷 1388 万文件约 3 分钟。
- **省内存**：目录节点 72 字节定长，61 万文件的树常驻约 7 MB。
- **安全优先**：只移入回收站；逐项结果；删除前校验指纹；中断随时取消。
- **AI 只做加法**：本地规则先提名，模型只能确认或削弱结论，不能把未知项标成「安全」。
- **结论可复用**：明确可删清单落盘，重启仍在；支持日常清理、定时任务与规则。

## 功能

### 扫描与浏览
- 整盘 / 指定目录扫描，实时进度与取消。
- 树形浏览与大小占比，快速定位大目录。
- 智能列表：按体积、可清理度排序；「只看已选」快速筛选待删项。

### 清理
- 确认后统一移入回收站，无逐项提示音。
- 逐项显示成功 / 失败 / 取消，失败不影响其它项。
- 清理历史可回看；删除结果同步更新目录树与卷容量。

### AI 辅助
- 本地规则提名候选，AI 给出「可删 / 安全等级 / 原因」，并只用于确认或削弱。
- 支持多套服务商配置，各自独立保存 Key，可随时切换：
  - 火山方舟（平台 API 与 **Agent Plan** 两种端点）
  - DeepSeek 官方
  - OpenAI
  - Anthropic Claude（`/v1/messages` 协议）
- 常驻「AI 助手」已并入例行任务：用一句话生成定时任务草稿。

### 定时任务与规则
- 统一的「定时任务」列表，支持执行 / 编辑 / 删除。
- 三种创建方式：手动、规则匹配、AI 生成。
- 例行任务：按周期（每天 / 每周 / 每月）清理指定目录；默认需人工确认。
- 规则：目录 + 文件名正则 + 可选「仅清理 N 天前」，随每日定时清理执行；单次上限 2000 个文件 / 20 GB，不跟随符号链接。
- 自动学习：从历史删除习惯中给出例行任务建议，可接受或忽略。

### 系统与界面
- 菜单栏常驻：剩余空间监控、低空间提醒、定时清理。
- 8 种界面语言：简体中文、繁体中文、英文、日语、韩语、印地语、印尼语、俄语。
- 统一 Lucide 图标、深浅色主题。

## 安全与隐私

- 删除只走系统回收站，应用内没有「永久删除」。
- AI 请求只发送必要文本与脱敏元数据；不上传文件内容。使用前需显式开启并同意。
- API Key 保存在本机（`~/Library/Application Support/Sift/`，权限 `0600`），不写入设置文件、不随仓库分发。
- 规则与例行任务创建的清理一律为「执行前确认」模式。

## 已知限制

- 目前仅提供 macOS 版本；Windows / Linux 仍在开发中。
- AI 功能需要自备 API Key，并遵循对应服务商的计费与条款。
- Claude 的模型名需与账号可用的模型一致。
- 定时任务列表的「上次执行时间」尚未在所有入口展示，将在后续版本补齐。

## 升级与验证

- 设置、清理历史与定时任务在版本间兼容；旧的单套 AI 配置会自动迁移为第一套配置。
- 自检：`cargo test --workspace`、`cargo clippy --workspace --all-targets`、`pnpm check`。
