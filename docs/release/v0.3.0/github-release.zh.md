## 亮点

0.3.0 让 Sift 开始认识「这台机器上装了什么」：应用、包管理器、项目不再只是散落的目录，而是进入每次分析的环境上下文。

- 新增环境清单：macOS 应用身份、包管理器版本、项目 manifest/lockfile。
- 每次分析都带上脱敏环境上下文，AI 能解释路径属于哪个应用/工具链。
- 维护建议开始沉淀：`cleanCache`、`pruneStore`、`removeOldVersion` 等，带状态生命周期。
- 应用卸载计划：识别支持目录、缓存、偏好、容器、日志，并区分自动安全/需确认/保留。
- 可撤销卸载：选中项移入 Sift 隔离区并写 manifest，可一键恢复；计划外的路径会被拒绝。
- Dashboard 新增「环境」面板，显示应用、包管理器和维护建议。

## 更新内容

### 环境上下文

- `ScanContext` 包含应用、包管理器、项目三类事实；路径脱敏为 `~/...`，不发送文件内容。
- 环境清单有 5 分钟缓存；重复分析不会反复探测每个应用和工具链。
- 上下文进入 AI system prompt，并限制为最多 40 个应用 / 20 个包管理器 / 20 个项目。

### 维护知识沉淀

- 维护建议按 `Proposed → Validated → Rejected/Stale` 管理。
- 本次扫描消失的建议标记为 `Stale`，已验证/已拒绝的状态跨扫描保留。
- 建议只是数据：动作是封闭枚举，不包含 shell 命令。

### 应用卸载

- 只读计划：按约定识别 `Application Support`、`Caches`、`Preferences`、`Containers`、`Saved Application State`、`Logs`、`LaunchAgents`。
- 处置分级：缓存/保存状态默认自动安全，支持目录/容器/偏好需确认，缺失路径不展示噪音。
- 执行：选中项移动到 Sift 隔离区（同卷 rename，跨卷回退复制），记录 manifest；恢复按 manifest 逆序移回。
- 安全：执行前按应用重新生成计划，前端传入的路径必须在计划内。

### 界面

- Dashboard 新增 Environment 面板：应用数、包管理器数、项目数、维护建议状态。
- 支持手动刷新环境清单。

## 安装说明

- **macOS**：打开 dmg，把 Sift 拖进「应用程序」。App 已签名并公证（可离线验证）；dmg 本身未单独公证，属正常流程。
- **Windows**：安装包暂未签名，SmartScreen 可能提示「未知发布者」，选择「更多信息 → 仍要运行」。
- **Linux**：AppImage 添加可执行权限后运行；deb 用系统包管理器安装。

## 已知限制

- 应用清单目前仅 macOS；Windows/Linux 返回空应用列表，上下文结构保持不变。
- 包管理器能力已编目并展示为建议，但尚未提供命令执行 UI；不会自动执行任何命令。
- 本版本的维护建议来自本地能力目录，尚未解析模型返回的 maintenance 建议。
- 卸载执行已有后端命令与隔离区/撤销路径，但还没有专门的前端流程；系统级/管理员动作不会执行。
- 环境刷新目前是 5 分钟时间缓存，尚未在应用安装/卸载时事件驱动刷新。
